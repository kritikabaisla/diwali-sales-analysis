# Diwali Sales Analysis

Exploratory data analysis (EDA) of Diwali sales data using Python, to understand which customers, states, and products drive the most sales.

## Dataset
- File: `Diwali Sales Data.csv`
- Contains customer details (gender, age group, marital status, state, occupation) and purchase details (orders, amount)

## Tools Used
- Python
- Pandas and NumPy for data cleaning and analysis
- Matplotlib and Seaborn for visualization
- Google Colab

## What I Did
1. Loaded the dataset and inspected its structure
2. Cleaned the data (handled missing values, fixed data types)
3. Explored the data with charts (count plots and bar plots)
4. Analyzed sales by gender, state, and more

## Key Findings
- Female customers placed far more orders than male customers
- Uttar Pradesh had the highest number of orders, followed by Maharashtra and Karnataka
